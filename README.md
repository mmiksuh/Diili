# Diili

Diili on käytettyjen tuotteiden ostoavustajan MVP-prototyyppi.

## Mukana
- älykäs tuotteen hakukenttä (demo)
- diili-pisteet
- Paras diili -valinta
- kokonaishinnan esitys
- markkina-arvio
- "Hyvä ostos" -arvio
- hintavahti-UI

## Käynnistys

```bash
npm install
npm run dev
```

Tuotantobuild:

```bash
npm run build
```

Tämä versio käyttää demo-dataa. Seuraava vaihe on liittää oikeat markkinapaikkalähteet/API:t.
